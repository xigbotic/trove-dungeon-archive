# Trove Dungeon Blueprint Archive

An unofficial, noncommercial archive for preserving Trove's dungeon and lair builds, including creations contributed by players.

The `v1.00/` and `v2.06/` folders preserve the original paths for blueprint pieces, dungeon assembly manifests, and related layout files. Ten v1.00 Ecospire blueprints are preserved as-is because they could not be decoded during review.

See [Contributor Credits](CONTRIBUTORS.md) for credits found in the files. If you know who built something, please share the filename and a public source so we can credit them.
